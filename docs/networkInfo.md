# 네트워크 정보

**IP 대역:** `192.168.0.171` ~ `192.168.0.190`

Nginx는 2대, HAProxy는 3대이며 HAProxy는 각 물리 PC에 1대씩 있다.
FastAPI·Grafana·Prometheus는 API 호스트, Nginx·Loki는 웹 호스트, DB는 DB 호스트에 배치한다.
PC 번호 대신 역할로 구분하며 상세 배치는 [ADR-002](adr/002-windowsServerAllocation.md)를 따른다.

웹 요청은 HAProxy 181 → Nginx 177·178 → HAProxy 179 → FastAPI 175·176 순서다.
179는 Nginx에서 FastAPI로 연결하는 프록시이며 DB 접속 주소와 구분한다.
